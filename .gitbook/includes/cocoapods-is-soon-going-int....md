CocoaPods is soon going into maintenance mode and we will stop releasing versions of the MapsIndoors SDK via CocoaPods when its repository switches to read-only on December 2, 2026. You should use Swift Package Manager instead. See [#swift-package-manager](../../sdks-and-frameworks/ios/getting-started/create-a-new-project.md#swift-package-manager "mention") for information about using MapsIndoors from Swift Package Manager.
