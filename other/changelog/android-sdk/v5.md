# V5

## \[5.0.0]

Version 5 is a major release. The SDK is now written in Kotlin and its public API has been reshaped around Kotlin conventions, with no compatibility layer for the V4 API. To upgrade an existing app, follow [Migrating from V4 to V5](../../../sdks-and-frameworks/android/getting-started/migrating-from-v4-to-v5/README.md), which lists every change and its replacement.

### Changed

* **New minimum requirements.** `minSdk` 24, `compileSdk` 37 and Android Gradle Plugin 9.2.1 or newer. Kotlin apps must build with Kotlin 2.2 or newer.
* **Listeners.** Most single-purpose listener interfaces are replaced by `MPResultListener<T>`, `MPStateListener<T>` and `OnMPEvent<E>`, with sealed `MPEvent` types for clicks, selection, floor updates and camera events.
* **`MPCameraEvent`** has moved to `com.mapsindoors.core`, and its constants are now PascalCase (`IDLE` → `Idle`, …).
* **Sealed types.** `MPGeometry`, `MapsIndoorsException`, `MPVenueStatus` and the dataset-cache statuses are sealed.
* **Kotlin DSL builders** for `MPQuery`, `MPFilter`, `MPMarkerOptions`, `MPTileOverlayOptions`, `MPCameraPosition` and other option types. `MPMarkerOptions`, `MPTileOverlayOptions`, `MPLatLng`, `MPMapStyle` and `MIError` are immutable.
* **Route animation** is always speed-based (`MPDirectionsRendererOptions.animationSpeed` / `animationMinDuration`) and respects reduced-motion settings.

### Removed

* `MapControl.setMapLabelTextSize`, the three-argument `MapControl.setMapLabelFont`, `MapsIndoors.isAPIKeyValid`, `MPDirectionsRenderer.setAnimatedPolyline`, `MPDirectionsRenderer.setPolylineColors`, `MapControl.setOnWillUpdateLocationsOnMap` and the `MPDirectionsService(Context)` constructor.
* The `mapbox-ndk27` artifact. `mapbox-v11` now ships the 16 KB page-aligned Mapbox build.
